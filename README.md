# Spam Message Detector

This is a beginner Data Science project that detects whether a message is Spam or Normal using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning

## How it Works
1. Load SMS dataset
2. Convert messages to numerical features using CountVectorizer
3. Train Naive Bayes model
4. Predict whether message is Spam or Normal

## Example

Input:
You won a free lottery ticket

Output:
Spam Message
